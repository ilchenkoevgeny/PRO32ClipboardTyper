# PRO32 Clipboard Typer

.NET 8 / WinForms / x64.

Утилита для ввода локального clipboard в удалённую сессию PRO32 Connect, в том числе в сценарии:

`локальный ПК → PRO32 → удалённый ПК A → RDP → ПК B`

где clipboard redirection между ПК A и ПК B запрещён политикой RDP.

## Режимы

### Legacy — режим по умолчанию

- `Ctrl+Shift+V` — посимвольный ввод локального буфера через CDP.
- Двойной клик по иконке в трее — тот же Legacy-ввод.
- `Ctrl+Shift+C` — остановить текущий ввод.

Legacy сохранён как максимально совместимый режим.

### Turbo — быстрый клавиатурный ввод для RDP

Отдельный пункт меню трея.

Turbo не использует clipboard вложенной RDP-сессии. Он отправляет обычные keyboard events, как Legacy, но ставит `keyDown/keyUp` в очередь пакетами и реже ждёт подтверждения CDP.

Текущие параметры:

- задержка печатного символа: 3 мс;
- пакет: 24 символа;
- пауза между пакетами: 8 мс.

Если конкретная RDP-сессия или приложение начинает пропускать символы, используй Legacy.

### Буфер PRO32 — только первый удалённый ПК

В отдельном подменю находятся:

- отправка clipboard на первый компьютер, к которому подключён PRO32;
- получение clipboard с этого компьютера через штатные `Ctrl+C/Ctrl+V`.

Эти команды **не обходят запрет clipboard redirection во вложенной RDP-сессии**. Если clipboard между ПК A и ПК B запрещён политикой, Typer не может прочитать clipboard ПК B через PRO32.

## Автоматический запуск PRO32

Typer сам:

1. Ищет `PRO32 Connect Dashboard`.
2. Проверяет рабочий CDP на `127.0.0.1:9222`.
3. Если PRO32 не запущен — запускает его с нужными CDP-параметрами.
4. Если PRO32 запущен без рабочего CDP — завершает Dashboard и запускает заново.
5. Повторяет проверку перед операциями ввода.

Отдельный batch-файл для запуска PRO32 больше не нужен.

## Иконка

Перед сборкой `extract-pro32-icon.ps1` пытается взять оригинальную иконку из установленного `PRO32 Connect Dashboard.exe` и создаёт `Assets\pro32.ico`.

Если PRO32 на машине сборки не установлен, используется стандартная системная иконка. Сгенерированный `Assets\pro32.ico` не хранится в Git.

## Сборка

Запусти:

```bat
publish-win-x64.cmd
```

Готовый файл:

```text
PRO32ClipboardTyper\bin\Release\net8.0-windows\win-x64\publish\PRO32ClipboardTyper.exe
```
