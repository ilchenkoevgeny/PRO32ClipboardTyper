# PRO32 Clipboard Typer

.NET 8 / WinForms / x64.

Утилита предназначена прежде всего для сценария, когда локальный ПК подключён к промежуточному компьютеру через PRO32 Connect, а уже на нём открыта RDP-сессия, в которой clipboard redirection запрещён политикой.

## Режимы работы

### Legacy — режим по умолчанию

- `Ctrl+Shift+V` — посимвольный ввод текста из локального буфера через CDP.
- Двойной клик по иконке в трее — тот же Legacy-ввод.
- `Ctrl+Shift+C` — остановить текущий ввод.

Legacy-режим сохранён как максимально совместимый и остаётся поведением по умолчанию.

### Turbo — быстрый клавиатурный ввод для RDP

Отдельный пункт меню трея.

Turbo **не использует clipboard удалённой RDP-сессии**. Он отправляет те же клавиатурные события, что и Legacy, поэтому работает в сценарии, где RDP clipboard запрещён.

Отличие от Legacy: события `keyDown/keyUp` передаются в CDP пакетами и подтверждаются реже, а задержка между печатными символами уменьшена. Это заметно ускоряет длинный ввод.

Если конкретная RDP-сессия или приложение начинает пропускать символы, следует использовать Legacy.

### Буфер PRO32 (только первый удалённый ПК)

Эти команды вынесены в отдельное подменю, чтобы не путать их с вложенной RDP-сессией.

- «Отправить буфер на первый удалённый ПК» — синхронизация clipboard между локальным ПК и компьютером, к которому подключён PRO32.
- «Получить буфер с первого удалённого ПК» — получение clipboard именно с этого компьютера.

Они **не обходят запрет clipboard redirection внутри RDP**. Если на первом удалённом ПК открыт RDP к другому серверу и буфер RDP запрещён, данные clipboard между этими двумя машинами не передаются.

## Почему нельзя напрямую получить буфер из вложенного RDP

Когда RDP clipboard redirection запрещён политикой, clipboard удалённой RDP-сессии не передаётся клиентскому компьютеру. Typer видит только PRO32-сессию первого удалённого ПК и не имеет обратного канала к clipboard второй машины.

Для получения clipboard второй машины нужен дополнительный разрешённый канал: отдельный helper/сетевой канал, разрешённая переадресация диска/файлов или другой механизм передачи данных.

## Автоматический запуск PRO32

При запуске Typer автоматически:

1. Ищет процесс `PRO32 Connect Dashboard`.
2. Проверяет реальное CDP-соединение на `127.0.0.1:9222`.
3. Если PRO32 не запущен — запускает его с нужными CDP-параметрами.
4. Если PRO32 запущен неправильно — завершает Electron-процессы Dashboard и запускает его заново.
5. Перед каждой операцией проверяет состояние PRO32 повторно.

## Иконка

- В трее используется оригинальная иконка установленного `PRO32 Connect Dashboard.exe`.
- Перед сборкой `extract-pro32-icon.ps1` извлекает оригинальную иконку в `Assets\pro32.ico`.
- Если PRO32 не найден по стандартному пути, используется резервная иконка из проекта.
